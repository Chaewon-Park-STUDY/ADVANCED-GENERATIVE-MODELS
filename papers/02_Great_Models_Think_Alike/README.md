# Great Models Think Alike and this Undermines AI Oversight

- 학회: ICML 2025 Spotlight
- 논문: https://arxiv.org/abs/2502.04313
- 원본 코드: https://github.com/model-similarity/lm-similarity

## 선정 이유

verifier를 단일 모델이 아닌 여러 모델로 구성하면 개별 verifier의 편향을 상쇄할 수 있을 것으로 기대할 수 있다. 그러나 이러한 기대는 각 모델이 서로 독립적으로 판단한다는 전제에 기반하며, 이 전제가 성립하는지는 별도로 검증되어야 한다. 본 논문은 모델 간 오류의 유사도를 정량화하는 지표를 제안하고, 이 유사도가 AI oversight의 신뢰성을 저해함을 보인다. 제안된 지표가 패키지로 공개되어 있어 프로젝트의 multi-verifier 실험에 직접 적용할 수 있다는 점에서 선정하였다.

## 문제의식

언어 모델의 성능이 인간이 감독하기 어려운 수준에 가까워지면서, 다른 언어 모델이 평가를 수행하는 LLM-as-a-judge와 약한 모델의 라벨로 강한 모델을 학습시키는 weak-to-strong generalization 등 AI가 AI를 감독하는 방식이 확산되고 있다. 그러나 감독하는 모델과 감독받는 모델이 동일한 문항에서 동일한 방식으로 오류를 범한다면, 감독 과정은 해당 오류를 포착하지 못한다. 저자들은 이러한 상관된 오류가 AI oversight의 근본적인 위험 요인이 될 수 있다고 보고, 모델 간 유사도를 측정하고 그 영향을 분석한다.

## 방법: CAPA

CAPA, 즉 Chance Adjusted Probabilistic Agreement는 두 모델이 같은 문항에서 같은 방식으로 오류를 범하는 정도를 측정하는 지표이다. 두 모델의 정확도가 높을수록 우연에 의한 일치가 커지므로, 이 부분을 보정한 뒤 남는 일치도를 유사도로 정의한다. 값이 0이면 두 모델이 독립적인 수준이고, 클수록 오류 양상이 유사함을 의미한다.

기존 지표인 error consistency와 비교하면 두 가지 차이가 있다. 첫째, 두 모델이 서로 다른 오답을 선택한 경우를 덜 유사한 것으로 구분한다. 둘째, 각 선택지에 부여된 확률을 반영하여 모델의 확신도까지 고려한다.

계산 절차는 다음과 같다.

1. 관측 일치도: 문항마다 두 모델의 선택지별 확률을 곱해 더한 뒤, 전체 문항에 대해 평균한다.
2. 기대 일치도: 각 모델이 정답에 부여한 평균 확률을 정확도로 보고, 서로 독립인 두 모델이 우연히 같은 답을 선택할 확률을 계산한다.
3. CAPA = (관측 일치도 − 기대 일치도) / (1 − 기대 일치도)

## 핵심 결과

1. LLM judge의 affinity bias: judge는 자신과 유사한 모델을 더 높게 평가하며, 이 경향은 평가 대상 모델의 실제 정확도를 통제한 뒤에도 유의하게 나타났다. 9개 judge와 39개 평가 대상 모델에 대해 judge 점수와 유사도 간 평균 Pearson 상관계수는 0.84였다.
2. Weak-to-strong generalization: 약한 모델과 강한 모델의 유사도가 낮을수록 학습을 통한 성능 향상이 컸다. 이는 서로 다른 모델이 상호 보완적인 지식을 가지기 때문으로 해석된다.
3. 성능과 유사도의 관계: OpenLLM Leaderboard의 130개 모델을 분석한 결과, 모델 성능이 높아질수록 오류 양상이 더 유사해지는 경향이 나타났다. 이 경향은 서로 다른 개발사의 모델 간 비교에서도 유지되었다.

## 한계

- CAPA는 정답이 정의된 객관식 문항에서만 계산할 수 있다.
- 유사도와 감독 성능 사이의 상관관계를 보였을 뿐, 인과관계를 입증하지는 않았다.
- weak-to-strong 실험은 12개 모델 쌍과 15개 과제로 규모가 제한적이다.

## 직접 실행 결과: 가상 데이터 예시

논문 실험의 재현이 아니라, 가상으로 생성한 두 모델의 응답에 lm-sim 라이브러리를 적용하여 CAPA의 성질을 확인한 예시이다. 두 모델의 정확도는 모두 80%이며 문항 수는 2,000개이다.

| 상황 | 4지선다 CAPA | 4지선다 EC | 통과/탈락 CAPA | 통과/탈락 EC |
| --- | --- | --- | --- | --- |
| 독립적으로 오류 | −0.026 | −0.023 | −0.017 | −0.017 |
| 같은 문항에서 다른 오답 | 0.615 | 1.000 | 1.000 | 1.000 |
| 같은 문항에서 같은 오답 | 1.000 | 1.000 | 1.000 | 1.000 |

통과/탈락 판정에 확신도를 함께 부여한 경우, 두 모델이 같은 문항에서 오류를 범할 때의 결과는 다음과 같다.

| 확신도 | CAPA, 확률 버전 |
| --- | --- |
| 0.99 | 0.938 |
| 0.8 | 0.260 |
| 0.6 | 0.025 |

- 4지선다에서 error consistency는 서로 다른 오답을 고른 경우에도 1.0을 부여하지만, CAPA는 0.615로 이를 구분한다.
- 선택지가 두 개인 통과/탈락 판정만 사용하면 CAPA가 error consistency와 같아져 구분력이 사라진다.
- 확신도를 함께 사용하면 구분력이 회복된다.
- 따라서 프로젝트의 verifier 출력은 통과/탈락 판정과 확신도를 함께 산출하도록 설계해야 한다.

```python
cobsp += np.sum(sample_a * sample_b)                  # 관측 일치도: 선택지별 확률의 곱의 합
phat_a += sample_a[gt[idx]]                           # 정답에 부여한 평균 확률
frac += 1 / (len(sample) - 1)                         # 오답 확률이 나머지 선택지에 균등하게 분포한다고 가정
cexp = p_hat_a * p_hat_b + frac * (1 - p_hat_a) * (1 - p_hat_b)   # 기대 일치도
kappa = (observed - expected) / (1 - expected)
```

## 프로젝트 연결

- 시사점: 여러 모델을 verifier로 사용하더라도 모델 간 오류가 상관되어 있다면 cross-verification의 효과는 제한된다.
- 재학습 세대마다 verifier 쌍의 CAPA를 계산하여, recursive training이 진행됨에 따라 verifier 간 유사도가 증가하는지 추적한다.
- CAPA 계산에는 ground truth가 정의된 고정 evaluation set이 필요하다. 예를 들어 real samples에는 accept, degraded synthetic samples에는 reject를 정답으로 부여할 수 있다.
- 차별점: 본 논문은 이미 학습이 완료된 모델 간 유사도만을 분석하였다. 본 프로젝트는 recursive training 과정에서 verifier 간 유사도가 어떻게 변화하며, 이것이 model collapse 완화 효과에 어떤 영향을 미치는지 분석한다.
